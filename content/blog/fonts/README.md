# Typst fonts

The native compiler uses Libertinus Serif, embedded in the compiler, for consistent local preview and GitHub Pages builds.

To use Warnock Pro, add licensed desktop `.otf` or `.ttf` font files for that family here. Include regular, italic, bold, and bold italic faces. The compiler prefers Warnock Pro when those files are available. Ensure your font license permits using and committing the font files before placing them in the repository.

An Adobe Fonts web stylesheet cannot supply fonts to the native Typst compiler. The homepage continues to use its existing Adobe Fonts configuration.
