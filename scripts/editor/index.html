Typst help

Headings: = Heading. Bold: *text*. Italic: _text_. Links: #link("https://example.com")[text]. Lists start with -. Use Cmd/Ctrl+B and Cmd/Ctrl+I for formatting and Cmd/Ctrl+S to save.

Inline math: $x^2$. Display math includes spaces: $ sum_(i=1)^n i $. Write native Typst directly, including functions, tables, diagrams, and show rules. No Markdown fences are needed around Typst.

Paste or drop images into the source pane, or choose Add image. The editor inserts #image("./image.png", width: 100%, alt: "Image description"). Add useful alternative text. New posts are saved as drafts before the first upload.

The preview uses a persistent local Typst compiler. Errors keep the last valid preview visible. Source saves to index.typ; metadata saves to post.json. Drafts may be saved with errors. Ready to publish requires valid Typst; push to main to publish.

Edit the URL and save to rename a post. Images move with it. Changing a published URL replaces its old address.

Unsaved source is backed up in this browser. Previous Markdown backups remain untouched. Typst writing guide
